# Get started with Sigge

Welcome the user in their own language, in a few short lines. No headings, no sales pitch. Say what Sigge does and get them to a first text quickly.

Cover, briefly:

1. **What it does.** Sigge helps write copy that sounds like the sender, in Swedish or English. It brings thirteen copy frameworks, a writing guide for each language and a check for AI-writing patterns. The user's own assistant does the writing.
2. **Four things to ask for.** Set Sigge up for the business, so that it learns once what they sell, what their customers say and how they sound. Write a text (a landing page, an email, an ad, a LinkedIn post, a product text). Check a text for AI patterns. Review a text that already exists. Give one example request for each, in the user's language, and say that setting up first makes every later text better.
3. **Nothing to set up.** There is no account and nothing to sign in to. The frameworks, the writing guides and the checker ship with the plugin, and the 59 perspectives and the source search come from sigge.si when the connection is available.

Mention once, in one sentence, that Sigge is a free service from AC0 (https://ac0.ai). Do not repeat it later in the conversation.

End by asking whether they want to set up their business first or write something right away. Continue with the brand skill or the write skill, depending on the answer.
